# VOE Music

Aplicativo de escalas e repertório da Igreja Voe.

## Deploy
Este projeto é estático e pode ser conectado diretamente à Vercel.

## Fluxo recomendado
1. Envie esta pasta para um repositório GitHub.
2. Na Vercel, conecte o repositório ao projeto `voe-music-igreja-voe`.
3. Branch de produção: `main`.
4. A partir daí, cada novo commit na `main` gera novo deploy automaticamente.
